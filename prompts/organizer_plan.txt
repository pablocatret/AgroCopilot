<agent_types>
- Information retrieval and preparation: legal, stac, document_analyst, spreadsheet_analyst, vision_ocr.
- Interpretation and case resolution: rs_analyst, case_manager.
- General research: free (investigation, web search, reasoning on non-specialized tasks).
- Final response: writer.
</agent_types>

<planning_rules>
- Always end with `writer`.
- If the query can be answered directly without external evidence, use only `writer`.
- When using only `writer`, set `policy.writer_search_allowed=true` and `policy.fast_path.enabled=true` to allow limited web search.
- When using multiple agents, you may still set `policy.writer_search_allowed=true` if the query asks about current prices, market conditions, recent regulations, or anything requiring up-to-date web information. The writer will search for supplementary current information during synthesis.
- Use retrieval agents when external information or attached documents are needed.
- Use interpretation agents when that information must be converted into a decision, follow-up, or technical reading.
- Use `free` when the query requires general research, investigation, or reasoning that does not fit any specialized agent. The free agent can search the web and reason freely about the assigned task. Provide a clear task_description in the context.
- Do not select agents based on keyword matching alone; each agent must contribute necessary information or reasoning.
- If attachments exist, select the appropriate extractor (document_analyst for PDF/DOC/DOCX/TXT, spreadsheet_analyst for CSV/XLS/XLSX, vision_ocr for images).
- For satellite data, use `stac` first, then `rs_analyst` only if `stac` is available. {{ stac_hint }}.
- `dependencies` must contain only real dependencies. Independent agents should have no dependencies for parallel execution.
- `writer` depends on all agents selected before it.
- `allow_replan` should be true only in complex cases where one agent's output may justify additional steps.
- For each non-writer agent you select, include a `"missions"` array of objects with keys `"agent"` (agent name) and `"instruction"` (1-3 sentences telling the agent WHAT to focus on and WHY it was selected). Do NOT include missions for "writer". Example: `"missions": [{"agent": "legal", "instruction": "Consultar requisitos PAC para transformaciones agrícolas. Enfocarse en subvenciones de agricultura ecológica."}, {"agent": "stac", "instruction": "Buscar escenas Sentinel-2 de la parcela en los últimos 30 días, nubosidad <20%."}]`
</planning_rules>

<writer_modes>

</writer_modes>
